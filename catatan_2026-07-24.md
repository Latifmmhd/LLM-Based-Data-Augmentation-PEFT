# Catatan Proyek — 24 Juli 2026

## Teknik Split Data (`split_data.ipynb`)
- Menggunakan **two-stage holdout split** dengan `train_test_split` dari `sklearn.model_selection`
- Proporsi akhir: **Train 70% / Val 15% / Test 15%**
- `test_size=0.3` pada split pertama, lalu `test_size=0.5` pada split kedua
- `random_state=42` untuk reproduktifitas
- Dataset: 12.600 baris

## Parameter Utama `train_test_split`
- **`test_size`** — menentukan proporsi data yang dialokasikan ke test/validation set
- **`random_state`** — seed untuk random number generator agar hasil split konsisten dan dapat direproduksi

## Parameter `TrainingArguments`
- **`num_train_epochs`** — jumlah epoch
- **`per_device_train_batch_size`** — batch size per GPU saat training
- **`per_device_eval_batch_size`** — batch size per GPU saat evaluasi

## Optimasi Hyperparameter (`hp_tuning_peft.py`)
- Menggunakan **Optuna** dengan `create_study()` (default: minimize)
- Setiap trial melatih model dan mengembalikan `training_loss`
- Trial dengan **nilai training loss terkecil** dianggap terbaik
- **Catatan**: penggunaan training loss kurang tepat, seharusnya validation loss (`eval_loss`) untuk menghindari overfit

## Tahap Fine-Tuning
- Dilakukan setelah memperoleh hyperparameter terbaik dari proses optimasi
- **Empat model pralatih**: IndoBERTweet, mBERT, XLM-RoBERTa Base, XLM-RoBERTa Large
- Menggunakan **PEFT + LoRA** (`r=8`, `lora_alpha=32`, `lora_dropout=0.1`)
- Max length tokenisasi: **128 token**
- Setiap model dilatih dengan best params dari file JSON (`best_params/`)

## Model Pralatih
- Model yang sudah dilatih sebelumnya pada dataset berskala besar oleh pihak ketiga
- Sudah memiliki pengetahuan linguistik umum, namun perlu fine-tuning untuk tugas spesifik
- Contoh: IndoBERTweet (tweet bahasa Indonesia), mBERT (104 bahasa), XLM-RoBERTa (100 bahasa)

## Evaluasi
- Menggunakan **scikit-learn** pada fungsi `compute_metrics()`:
  - `accuracy_score` — proporsi prediksi benar dari keseluruhan
  - `recall_score` — recall (macro average)
  - `precision_score` — precision (macro average)
  - `f1_score` — f1 (macro average)
  - `classification_report` — ringkasan precision, recall, f1, support per kelas
  - `confusion_matrix` — visualisasi matriks kebingungan
